Jewellery Manager

Jewellery dukaan ke liye GST billing, stock aur hisaab — bina internet ke bhi chalta hai.

Download

Latest version: …

Zaroorat

  • Windows 10 ya Windows 11 (64-bit)
  • Internet sirf licence activate aur update ke liye

Install kaise karein

  1. Upar Download button dabayein. File ka naam JewelleryManager-Setup.exe hai.
  2. Download poora hone par file par double-click karein.
  3. Windows ka blue warning aaye to neeche wala step dekhein.
  4. Installer me Next dabate jaayein, phir Install, phir Finish.
  5. Desktop par Jewellery Manager icon se app kholein aur dukaan ki details bharein.
  6. Licence screen par jo key humne di hai wo daalein aur Activate dabayein.

Windows warning aaye to (normal hai)

Blue screen par "Windows protected your PC" likha aaye to ghabraayein nahi:

More info→Run anyway
  1. More info par click karein.
  2. Neeche Run anyway button aayega, us par click karein.

Update

App khud naya version check karta hai. Popup aaye to Update now ya Later chunein. Aapka data (bills, stock, customers) update me surakshit rehta hai.
